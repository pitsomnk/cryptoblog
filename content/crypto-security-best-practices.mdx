## Seed Phrase Security

Your 12-24 word seed phrase is your master key. Here's how to protect it:

### The 3-2-1 Backup Rule

<div className="steps-container">
  <div className="step">
    <span className="step-number">1</span>
    <div className="step-content">
      <h4>3 Copies</h4>
      <p>Keep at least three copies of your seed phrase</p>
    </div>
  </div>
  <div className="step">
    <span className="step-number">2</span>
    <div className="step-content">
      <h4>2 Different Media</h4>
      <p>Use at least two different storage mediums (steel, paper, etc.)</p>
    </div>
  </div>
  <div className="step">
    <span className="step-number">3</span>
    <div className="step-content">
      <h4>1 Offsite Location</h4>
      <p>Store at least one copy in a different physical location</p>
    </div>
  </div>
</div>

### Storage Options Ranked

1. **🥇 Titanium/Steel Plates:** Fire and water resistant, lasts generations
2. **🥈 Cryptosteel Capsule:** Tamper-evident, portable
3. **🥉 Fireproof Safe + Paper:** Affordable but less durable
4. **❌ Cloud Storage:** Never store seed phrases digitally!

## Transaction Signing Best Practices

```javascript
// Example: Validating transaction before signing
async function safeSign(transaction) {
  // 1. Decode the transaction
  const decoded = decodeTransaction(transaction);
  
  // 2. Check recipient against whitelist
  if (!WHITELIST.includes(decoded.to)) {
    throw new Error("Unknown recipient address");
  }
  
  // 3. Verify value is within limits
  if (decoded.value > MAX_TRANSACTION_VALUE) {
    throw new Error("Transaction exceeds safety limits");
  }
  
  // 4. Simulate transaction first
  const simulation = await provider.call(transaction);
  if (!simulation.success) {
    throw new Error("Transaction simulation failed");
  }
  
  // 5. Sign only after all checks pass
  return wallet.signTransaction(transaction);
}
```

## Emergency Response Plan

If you suspect a compromise:

1. **Immediately** transfer remaining assets to a fresh wallet
2. **Revoke** all token approvals using revoke.cash
3. **Document** everything for potential recovery
4. **Report** to relevant authorities and chain analytics firms
5. **Never** reuse the compromised wallet or seed phrase

## Conclusion

Security in crypto is your personal responsibility. While it requires effort, following these practices will protect you from 95% of common attacks. Stay vigilant, verify everything, and when in doubt—don't click.
