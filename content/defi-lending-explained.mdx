## Understanding Interest Rates

DeFi lending uses **utilization-based** interest rate models:

```
Interest Rate = Base Rate + (Utilization × Slope)

Example:
- Base Rate: 2%
- Utilization: 70%
- Slope: 0.1

Interest Rate = 2% + (70% × 0.1) = 9%
```

<div className="info-box">
  <h4>💡 Key Concept: Kink Model</h4>
  <p>Most protocols use a "kink" model where rates increase slowly until a target utilization (usually 80%), then spike dramatically. This ensures liquidity remains available for withdrawals.</p>
</div>

## Step-by-Step: Lending on Aave

Here's how to start earning yield:

### 1. Connect Your Wallet

```javascript
// Using ethers.js to connect
const provider = new ethers.BrowserProvider(window.ethereum);
const signer = await provider.getSigner();
const aavePool = new ethers.Contract(POOL_ADDRESS, POOL_ABI, signer);
```

### 2. Approve Token Spending

```javascript
// Approve Aave to spend your USDC
const usdc = new ethers.Contract(USDC_ADDRESS, ERC20_ABI, signer);
await usdc.approve(POOL_ADDRESS, amount);
```

### 3. Supply Assets

```javascript
// Supply USDC to earn interest
await aavePool.supply(
  USDC_ADDRESS,  // Asset to supply
  amount,        // Amount in wei
  userAddress,   // On behalf of
  0              // Referral code
);
```

### 4. Monitor & Withdraw

```javascript
// Check your balance (aTokens)
const aUSDC = new ethers.Contract(A_USDC_ADDRESS, ERC20_ABI, signer);
const balance = await aUSDC.balanceOf(userAddress);

// Withdraw when ready
await aavePool.withdraw(USDC_ADDRESS, amount, userAddress);
```
