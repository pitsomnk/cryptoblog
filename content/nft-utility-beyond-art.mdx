### 5. Supply Chain & Authenticity

Luxury brands are leading the adoption of NFT-based authenticity:

```solidity
// Example: Luxury Good Authentication NFT
contract LuxuryAuthentication {
    struct Product {
        string serialNumber;
        string brand;
        uint256 manufactureDate;
        address currentOwner;
        bool isAuthentic;
    }
    
    mapping(uint256 => Product) public products;
    
    function verifyAuthenticity(uint256 tokenId) public view returns (bool) {
        return products[tokenId].isAuthentic;
    }
    
    function transferOwnership(uint256 tokenId, address newOwner) external {
        require(ownerOf(tokenId) == msg.sender, "Not owner");
        products[tokenId].currentOwner = newOwner;
        _transfer(msg.sender, newOwner, tokenId);
    }
}
```

**Brands Using NFT Authentication:**
- LVMH (Louis Vuitton, Dior)
- Nike (.SWOOSH)
- Prada
- Tiffany & Co.
